# 買い物リマインダーアプリ

シンプルなWebベースの買い物リマインダーです。買い物を忘れがちなユーザー向けに、項目とリマインド時刻を設定すると、指定時刻に通知またはアラートを表示します。

## 使い方

1. テキストボックスに買い物項目を入力します。
2. 必要であれば日時を設定します。
3. "追加" ボタンを押すとリストに追加されます。
4. リストアイテム横の "完了" ボタンで削除できます。
5. 設定した時刻になるとブラウザの通知（許可時）またはアラートが表示されます。

ブラウザのローカルストレージにデータを保存するので、ページを再読み込みしてもリストは維持されます。

## PWAとしての利用

1. モバイルやデスクトップのブラウザでページを開く。
2. メニューから「ホーム画面に追加」または「インストール」を選択。
3. アイコンがデバイスに追加され、単独アプリのように起動できる。

次回からはブラウザのUIなしで全画面表示され、オフラインでも動作します。

## PINロック機能

初回起動時にPINの設定を求められ、以後起動時にPINを入力しないと中身が見えません。PINはローカルストレージに簡単にハッシュ化して保存されます。
